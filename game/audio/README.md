# Audio

This folder holds the real song. Nothing is committed here — drop your own
track in and it plays.

## Dropping in the real song

1. Put the audio file here, e.g. `song.ogg` (`.wav` and `.mp3` also load).
2. Point `../charts/song.json`'s `"audio"` field at it, e.g.
   `"res://audio/song.ogg"`.
3. Set `"bpm"` and `"offset"` to match the track. `offset` shifts the whole
   chart in seconds, for songs whose first beat isn't at t=0.
4. Chart it: fill in `song.json`'s `notes` array (see `../charts/test.json`
   for the format — beats, not seconds; `Chart.load_from` resolves them
   against `bpm` and `offset` at load time).

Until a real file lands here, `song.json` ships with an empty `notes` array
and an `audio` path that doesn't exist yet. Play still runs — the HUD just
reports there's no audio until the file shows up, instead of erroring.

`click_120.wav` (generated by `../tools/make_click_track.py`, gitignored) is
a separate fixture used only by the engine's own Judge/Conductor tests
(`charts/test.json`, `scenes/play_test.tscn`, `tests/judge_test.gd`) — it has
nothing to do with the real song and shouldn't be touched when charting.
